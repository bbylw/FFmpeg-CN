FFmpeg 官方只提供源码。如果你想要已经编译好的可执行文件，可以在下面找到各平台的第三方构建入口。当前最新源码包：[ffmpeg-9.0.1.tar.xz](https://ffmpeg.org/releases/ffmpeg-9.0.1.tar.xz)。

## 获取源码

* 快照下载：[ffmpeg-snapshot.tar.bz2](https://ffmpeg.org/releases/ffmpeg-snapshot.tar.bz2)（另有 [git 快照](https://ffmpeg.org/releases/ffmpeg-snapshot-git.tar.bz2)）
* PGP 签名密钥：[ffmpeg-devel.asc](https://ffmpeg.org/ffmpeg-devel.asc)
* 在线浏览：[git.ffmpeg.org/gitweb/ffmpeg.git](https://git.ffmpeg.org/gitweb/ffmpeg.git)

你可以通过 [Git](https://git-scm.com/) 获取源码，使用命令：

```bash
git clone https://git.ffmpeg.org/ffmpeg.git ffmpeg
```

无法访问 Git，或者想加快克隆速度、减少带宽占用？可以改用上面的快照下载或 Browse 在线浏览。

FFmpeg 一直是一个高度实验性、由开发者驱动的项目。它是许多多媒体项目的关键组件，并且不断有新功能加入。开发分支的快照在 99% 的情况下都工作得很好，所以大家也放心使用它们。

## 发行版验证

所有 FFmpeg 发行版都使用[官方公钥](https://ffmpeg.org/ffmpeg-devel.asc)做了密码学签名，应当验证其真实性：

```text
pub   rsa2048 2011-04-26 [SC]
    FCF986EA15E6E293A5644F10B4322F04D67658D8
uid           [  full  ] FFmpeg release signing key <ffmpeg-devel@ffmpeg.org>
sub   rsa2048 2011-04-26 [E]
```

验证某个发行版的步骤：

1. 把官方公钥导入本地密钥环：

   ```bash
   $ curl https://ffmpeg.org/ffmpeg-devel.asc | gpg --import
   ```

2. 下载发行版 tarball 及其对应的签名（`.asc` 文件）。

3. 验证签名：

   ```bash
   $ gpg --verify ffmpeg-4.3.2.tar.xz.asc ffmpeg-4.3.2.tar.xz
   gpg: Signature made Sun 21 Feb 2021 06:35:15 AEST
   gpg:                using RSA key FCF986EA15E6E293A5644F10B4322F04D67658D8
   gpg:                issuer "ffmpeg-devel@ffmpeg.org"
   gpg: Good signature from "FFmpeg release signing key <ffmpeg-devel@ffmpeg.org>" [full]
   ```

可选地，你还可以核对 git 仓库与 tarball 是否一致：两者唯一的差异应该是 tarball 中没有 `.git*` 文件，并且包含一个记录版本号的 `VERSION` 文件。git 标签应当由 [EDDSA 密钥 DD1EC9E8DE085C629B3E1846B18E8928B3948D64](https://ffmpeg.org/git-tag-key.asc) 签名。

## 发行版

FFmpeg 项目大约每 6 个月发布一次新的大版本。在大版本之间还会发布点版本（point release），只加入重要的缺陷修复而不引入新功能。注意：这些发行版面向发行版打包者和系统集成人员。打算自己从源码编译的用户被强烈建议考虑使用开发分支（见上文），这是 FFmpeg 开发者实际工作的唯一版本。发行分支只是从开发分支中挑选部分变更，因此开发分支能获得数量更多、速度也更快的缺陷修复、新功能与安全补丁。

| 发行分支 | 代号 | 最新点版本 | 发布日期 | 分支切自 master |
| --- | --- | --- | --- | --- |
| 9.0 | "Lei" | 9.0.1 | 2026-08-12 | 2026-06-26 |
| 8.1 | "Hoare" | 8.1.2 | 2026-06-17 | 2026-03-08 |
| 8.0 | "Huffman" | 8.0.3 | 2026-06-18 | 2025-08-09 |
| 7.1 | "Péter" | 7.1.5 | 2026-06-20 | 2024-09-24 |
| 6.1 | "Heaviside" | 6.1.6 | 2026-06-20 | 2023-10-29 |

各 minor 版本的首发日期（官方新闻页）：8.1 "Hoare" 发布于 2026-03-16，8.0 "Huffman" 发布于 2025-08-22，7.1 "Péter" 发布于 2024-09-30，6.1 "Heaviside" 发布于 2023-11-10，5.1 "Riemann" 发布于 2022-07-22，4.4 "Rao" 发布于 2021-04-08。

以最新的 9.0.1 "Lei" 为例，其包含的库版本为：

```text
libavutil      61.  1.100
libavcodec     63.  1.100
libavformat    63.  1.100
libavdevice    63.  1.100
libavfilter    12.  1.100
libswscale     10.  1.100
libswresample   7.  1.100
```

每个分支的 tarball 都提供 xz、bzip2、gzip 三种压缩格式，附 PGP 签名（例如 `https://ffmpeg.org/releases/ffmpeg-9.0.1.tar.xz` 与 `.tar.xz.asc`）。各版本的 Changelog 可在 gitweb 查看（如 [n9.0.1 shortlog](https://git.ffmpeg.org/gitweb/ffmpeg.git/shortlog/n9.0.1)），8.1.2、8.0.3、7.1.5、6.1.6、5.1.10、4.4.8 等分支的下载与 Release Notes 入口见 [官方下载页](https://ffmpeg.org/download.html)，完整列表不再在此重复。

### 旧版本（停止维护的分支）

更早的版本保存在官方下载页的 [Old Releases](https://ffmpeg.org/olddownload.html) 页面。发行版通常在最后一个[下游发行版](https://trac.ffmpeg.org/wiki/Downstreams)（downstream）停止支持后被移入该页，也就是说上表之外的分支已不再获得官方更新。
